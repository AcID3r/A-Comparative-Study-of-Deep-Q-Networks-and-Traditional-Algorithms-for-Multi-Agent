# Reproducing this graph-search study

Run commands from the repository root. This is a local project archive; no public
repository or independently verified third-party reproduction is claimed.

The frozen settings are `configs/final_experiment.json` and
`configs/final_protocol.md`. The source/config/model/exclusion seal is
`results/validation/CP-07a-freeze`. Do not change sealed files to improve scores.
Saved final models are in
`results/raw/dqn_team/20261006T193829020826Z_42837111/models`.
They are inference checkpoints, not exact training-resume checkpoints.

Use Python 3.12.6 and the pinned packages in `requirements.txt`. Torch runs on
CPU with one thread. Install the CPU PyTorch build appropriate for your machine;
the measured archive reports its exact installed version. PDF text/raster review
uses the listed ReportLab, pdfplumber and pypdfium2 versions. Windows Times New
Roman fonts are used when available, with built-in Times fallback elsewhere.

```powershell
python -m unittest discover -v
python -m experiments.run_final --final
```

The second command verifies the seal and creates a fresh immutable run directory.
It evaluates 120 fresh geometries, 15,120 unique episodes and three timing rollouts
per episode, without training. The completion marker is written only after
all rows are saved and models pass preservation checks. Timing will differ on
another machine. Outcome/action reproduction is the relevant deterministic check.

For a completed run, substitute its directory for `<run>` below. Choose new
output locations because existing measured/generated outputs must be preserved.

```powershell
python -m evaluation.audit_final <run> --output <new-audit.json>
python -m evaluation.summarize_final <run> --output <new-summary-directory>
python -m evaluation.research_analysis <run> --audit <new-audit.json> --output <new-analysis-directory>
python -m evaluation.check_research_outputs <run> <new-analysis-directory> --output <new-checks.json>
python -m paper.build_manuscript <new-analysis-directory>
python -m paper.render_manuscript paper/paper.md --output paper/paper.pdf
python -m paper.check_manuscript <new-analysis-directory>
```

The paper builder replaces only generated manuscript files; it does not overwrite
measured data or the QENN reference. Its provenance records bind the manuscript
to analysis/table/figure hashes. The source `paper.tex` uses XeLaTeX/fontspec,
but no local TeX engine was available during development; the delivered readable
PDF is generated by ReportLab. Do not mistake that PDF for a validated
venue-specific Word template. CP-09 provides the separate Word formatting step.

To reproduce model training rather than inference, the archived CP-06b source,
config, training episode/action logs, five seeds and audit records provide its
evidence. Final-model weights were not retuned after development evaluations.
Crossing endpoints bias geometry and route lengths, and prioritized planning
can fail even on a solvable team task. These are experimental limitations, not
reasons to delete an unsuccessful row.
